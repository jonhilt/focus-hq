# The chief engineer's retro

At the engineering station (on the command deck), <kbd>E</kbd> opens Lt. Brennan's panel: the [ledger](ledger.md)'s report card, and **Start a retro**, which looks back over the last 14 days (or however many you choose, up to 60).

1. **The office gathers the evidence.** It digests every agent session's Claude Code transcript in the window (who said what to the agent, what the agent had just said before you spoke, QA's verdicts and the tool errors), and writes the digests, an index (with the tool errors seen in more than one session), the ledger and the closed goals with what their leads learned into `~/.focus/retros/<time>/`. Transcripts are found by their folder under `~/.claude/projects` (or `$CLAUDE_CONFIG_DIR/projects`): Claude Code names it after the session's working directory, and every agent works under `~/.focus/workspaces`.
2. **The engineer reads it.** A read-only Claude Code session like [Number One](number-one.md) (`Read`, `Glob` and `Grep`, `dontAsk`, no settings), with only that folder in reach. Reading a fortnight of sessions takes a while: up to 40 minutes, and it costs more than a chat turn. Their bubble and the console say what they're reading.
3. **They bring you findings:** a few lines on how the period went, up to ten proposals ranked by what they cost the office, what went well, and one-offs to watch. Each proposal says what keeps happening, cites the moments it rests on (a session's digest, a time and a quote), names the cheapest fix that would do (a **check** the office runs, a **QA rule**, a **pointer** in a prompt or the docs, or **delete** something that isn't earning its keep) and the number the next retro should watch. A proposal citing fewer than two moments in real sessions is dropped (`parseRetro` in `server/agents/retro.ts`), which keeps a retro from inventing generic advice.

The engineer changes nothing and files nothing: what to do with each proposal is your call. The latest retro is kept in `state.json` (one under way when Focus stops ends as interrupted), and each one's folder keeps the evidence and `retro.json`.
