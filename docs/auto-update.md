# Auto update

`pnpm run dev` and `pnpm start` keep the office on the latest code. Every few minutes the office fetches the branch your Focus checkout tracks (usually `origin/main`). When new commits land there, it waits until no agent is busy, fast-forwards, installs the dependencies again if `package.json` or the lockfile changed, with the package manager the lockfile names (`pnpm install --frozen-lockfile`), and rebuilds the client (`pnpm start` only). Then it restarts, and open browser tabs reload on their own. It skips the update when the checkout has local commits or uncommitted changes, and says so once for each new upstream commit (in the log and as a toast), with how many commits are in the way and how to clear them (push or `git pull --rebase`, or commit or stash); it stays off in demo mode. A couple of minutes after the restart, the office measures the new commit's [scorecard](scorecard.md). If the package manager it needs isn't on the PATH, it doesn't update: it says so once (for pnpm, run `corepack enable`) and tries again on its next check.
